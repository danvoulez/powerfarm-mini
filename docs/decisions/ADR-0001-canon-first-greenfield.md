# ADR-0001: Canon-first greenfield platform

**Status:** accepted

Powerfarm Platform is implemented as new Powerfarm-owned domain code rather than a fork of EmDash or Forge. The supplied repositories are used as implementation references.

Reason: Powerfarm's durable semantics differ materially from both source products. The platform must preserve Research, Identity, Continuity, evidence layers, explicit authority and reconstructable acts without inheriting a CMS or SDK-generator ontology as institutional truth.
